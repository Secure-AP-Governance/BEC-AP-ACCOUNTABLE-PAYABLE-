# Release Authority

## Purpose
Provide the final independent release decision based on the full evidence package.

## Scope
- Review all gate evidence
- Confirm release readiness
- Confirm rollback readiness
- Confirm release window and monitoring plan

## Responsibilities
- Require all preceding gate evidence.
- Validate the final deployment and rollback plan.
- Refuse release if critical findings remain.

## Required evidence
- Security evidence
- Identity evidence
- Operations evidence
- Infrastructure evidence
- Business/AP evidence
- Test evidence
- Audit evidence
- Rollback evidence

## Approval criteria
- All gate evidence exists and is reviewed.
- No critical findings remain open.
- Rollback and monitoring readiness are validated.

## Rejection criteria
- Any critical gate is missing or unresolved.
- No release authorization evidence exists.
